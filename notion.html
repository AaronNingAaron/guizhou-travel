🚆 Journey

Route：重庆 → 贵阳 → 南明河 → 甲秀楼 → 夜间城市

Look For：道路抬升/下沉、山体打断街道、高架与河流叠加、古楼与现代城市同框。

Photo Mission：甲秀楼+现代城市 / 河岸上的人 / 一张“山地城市” / 一张完全不是景点的贵阳。

Route：贵阳 → 荔波 → 小七孔

核心：卧龙潭 / 翠谷瀑布 / 水系森林 / 68级跌水 / 古桥

问题：我看到的是几个景点，还是同一套水—岩—森林系统？

Route：河边 → 风雨桥 → 主街 → 支路 → 坡地 → 观景台

观察：Architecture / Life / Tourism

问题：如果关闭所有景观灯，我还会怎样理解西江？
